# Anomalies detection on the presence of missing values in wearable data streams.

## Overview

This repository contains experiments on anomaly detection, missing values impact and online imputation
analyses applied to wearable COVID-19 datasets.

## Project Structure
<pre>
Anomalies-Detection/
│
├── Data/                      
│   # Plots and auxiliary files.
│   # Due to size constraints, the original datasets must be downloaded separately.
│   # Simulated and imputed data can be generated by running the scripts on the original data.
│
├── Results/                   
│   # Outputs and performance metrics for the anomaly detection task
│   ├── Imputers-AD/           
│   │   # Anomaly detection results using imputation methods (.csv files and plots)
│   └── Plots/                 
│       # Anomaly detection results without imputation (.csv files and plots)
│
├── Scripts/
│   ├── AD_Method/             
│   │   # Pipelines to apply the anomaly detection methods
│   │
│   ├── Imputation/            
│   │   # Pipelines to apply online imputation methods and the imputation results analysis
│   │   └── Analysis/
│   │
│   └── Missing_Simulators/    
│       # Pipelines to simulate missing data on the original dataset
</pre>
## Installation

Clone the repository:

git clone https://github.com/your-username/your-repo.git
cd your-repo

Install dependencies:

For anomalies detection method: pip install -r requirements_3_6_15.txt (Python 3.6.15)

For the rest: pip install -r requirements.txt

## Usage

Run the complete pipeline:

python run_all.py

Run only the imputation module:

bash run_imputation.sh

## Outputs

Results are saved inside:

Anomalies-Detection/Results/

Including:
- Patient-level results
- CD diagrams
- Aggregated metrics
